# FutureCar

AI-assisted automotive marketplace and research platform.

Search real listings from permitted sources, normalize them, identify the exact vehicle/version, enrich with technical/market evidence, then produce a source-aware AI analysis.

## MVP
- Advanced search and preferences
- Multi-source adapter architecture
- Listing normalization and deduplication
- Vehicle/version identification
- Technical and market enrichment
- Ownership-cost estimation
- Reliability / known-issue research
- AI-assisted analysis
- Side-by-side comparison
- Source attribution and confidence

## Data access
Use only official APIs, feeds, licensed datasets, partnerships, or other permitted access mechanisms. Never bypass authentication, anti-bot controls, rate limits, robots.txt or source terms.
